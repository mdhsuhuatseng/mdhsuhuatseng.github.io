# Antonio Hsu-Hua Tseng, MD — Academic Website

Officially approved website draft (3 November 2026). Static website for GitHub Pages.

## GitHub Pages
1. Create a public repository named `mdhsuhuatseng.github.io` under the matching GitHub account.
2. Upload the **contents** of this directory (not the directory itself): `index.html` and all `.png` / `.webp` images.
3. Go to Settings → Pages, choose Deploy from a branch, `main`, `/(root)`, then Save.
4. Confirm the website and publication links before printing QR-coded cards.

## Sections
Home; Academic Interests (titles only); Education & Experience; Publications (ten publications, titles link via DOI); Honors & Awards (five); ORCID footer. No professional biography, PubMed button, ongoing research or presentations.

The website has not been deployed automatically. All original graphics and physician photo should be checked for usage permissions before public publication.
